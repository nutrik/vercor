# VerCOR 0.4.0a1 Protocol-First API Rewrite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the complete, tested, documented, and committed VerCOR
0.4.0a1 protocol-first API rewrite.

**Architecture:** Public declarations normalize once into private immutable
component bindings. A validated workflow produces clock-step plans, the core
splits them at output boundaries, backends execute chunks through one driver,
and one output coordinator handles every provider. The original design made
legacy workflows available only from an opt-in compatibility namespace.

**Tech Stack:** Python 3.12+, JAX, jaxtyping-style annotations, frozen
dataclasses/PyTrees, pytest, mypy, Black, flake8, h5netcdf, flit.

## Global Constraints

- Root `vercor.__all__` is exactly `Clock`, `Coupler`, `Exchange`,
  `RectilinearGrid`, `RunState`, and `RuntimeOptions`.
- Component physics/constants are JAX-traced; dtype/workflow/topology/backend
  policy is static. Never branch in Python on traced values.
- All new production behavior follows TDD: observe the focused test fail for
  the intended missing behavior before editing production code.
- Public functions/classes have type hints and PEP 257 docstrings; frozen
  runtime containers are registered PyTrees.
- No registry, entry-point discovery, Pydantic, fan-in reducer, public prepared
  graph, or fractional-time subcycling.
- `output=None` performs no I/O. One coordinator owns enabled output for every
  backend/setup.
- Primary 0.4 modules contain no legacy aliases. The proposed compatibility
  boundary required explicit import changes.
- Optional JCM/Veros/CAMulator imports remain lazy. CAMulator is not installed
  or pinned during this work.
- Run focused tests, the fast suite, and the full suite before each commit.
- Update `PROGRESS.md` and `DEPENDENCIES.md` after every meaningful unit.
