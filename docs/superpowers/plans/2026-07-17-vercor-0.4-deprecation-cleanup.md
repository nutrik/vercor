# VerCOR 0.4 Deprecation Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove VerCOR-owned deprecated and legacy-looking compatibility evidence, test adapters, and obsolete guards while preserving the supported `0.4.0a1` API and behavior.

**Architecture:** Production already contains no explicit VerCOR deprecation machinery, so this is a boundary-and-test cleanup. Historical pre-redesign artifacts and their distribution lane are deleted; tests move from mutable legacy-shaped helpers to the current structural component and immutable output contracts; negative removal guards are deleted or rewritten as positive exact-owner contracts.

**Tech Stack:** Python 3.13, JAX, pytest/pytest-xdist, mypy, Black, flake8, compileall, coverage.py, Flit, GitHub Actions.

## Global Constraints

- Target release is exactly `0.4.0a1`.
- Follow `AGENTS.md`, `PROGRESS.md`, `DESIGN.md`, and `DEPENDENCIES.md`.
- Preserve supported `0.4.0a1` behavior and public signatures.
- Third-party JAX/Flax/xarray/netCDF4 deprecations are out of scope.
- Do not add aliases, wrappers, adapters, fallbacks, or warning suppressions.
- Prefer deletion and direct current APIs; use idiomatic Python, DRY, YAGNI, and SOLID.
- Preserve JAX purity, immutable PyTrees, tracing, dtype policy, typing, and documented optional-dependency boundaries.
- Report uncertain compatibility candidates instead of silently deleting them.
- Use the Conda environment with `conda run -n scipy`.
- Keep pytest output concise and update `PROGRESS.md` after each meaningful unit.
- Run the full suite before every implementation commit.

Rewrite the core shape in `tests/_distribution_support.py` to:

```python
@dataclass(frozen=True)
class BuiltDistributions:
    """Paths to the VerCOR and native public-plugin distributions."""

    wheel: Path
    sdist: Path
    plugin_wheel: Path
    build_pythonpath: str


def _existing_distributions(
    wheel: Path,
    sdist: Path,
    plugin_wheel: Path,
) -> BuiltDistributions:
    """Validate and return externally supplied VerCOR and plugin artifacts."""

    if (
        wheel.name != EXPECTED_WHEEL_NAME
        or sdist.name != EXPECTED_SDIST_NAME
        or plugin_wheel.name != EXPECTED_PLUGIN_WHEEL_NAME
    ):
        raise ValueError(
            f"expected VerCOR {EXPECTED_VERSION} artifacts named "
            f"{EXPECTED_WHEEL_NAME!r}, {EXPECTED_SDIST_NAME!r}, and "
            f"{EXPECTED_PLUGIN_WHEEL_NAME!r}"
        )
    if not all(path.is_file() for path in (wheel, sdist, plugin_wheel)):
        raise ValueError(
            f"VerCOR {EXPECTED_VERSION} or plugin artifacts are missing: "
            f"{wheel}, {sdist}, {plugin_wheel}"
        )
    return BuiltDistributions(wheel, sdist, plugin_wheel, "")
```

```python
def _accumulate_frames(frames: Sequence[OutputFrame]) -> _OutputAccumulator:
    first, *remaining = frames
    accumulator = _OutputAccumulator.zeros_from_frame(first).add_frame(first)
    for frame in remaining:
        accumulator = accumulator.add_frame(frame)
    return accumulator


def _period_variables(
    accumulator: _OutputAccumulator,
    *,
    time_dim: str,
    reverse_value_dims: bool = False,
) -> dict[str, OutputVariable]:
    return {
        name: period_mean_sample_to_output_variable(
            sample,
            time_dim=time_dim,
            value_dims=tuple(reversed(sample.dims)) if reverse_value_dims else None,
            dimension_order=accumulator.dimension_order,
        )
        for name, sample in accumulator.mean_frame().variables.items()
    }
```
