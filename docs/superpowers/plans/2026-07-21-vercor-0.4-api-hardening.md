**Goal:** Make the existing VerCOR 0.4 extension API reproducible, installable, consistently typed, and accurately documented without replacing its assembly model.

**Architecture:** Preserve explicit dependency injection and the public Component, Workflow, ExecutionBackend, TopologyPolicy, output, and immutable-state contracts. **Tech Stack:** Python 3.12+, JAX/PyTrees, NumPy, pytest/pytest-xdist, mypy, Black, flake8, flit, optional Veros and CAMulator/Torch adapters.

~~~python
def _validate_component_identity(declaration: _ComponentDeclaration) -> None:
    """Reject lifecycle replacement of static component identity."""

    validate_component_contract(declaration.component)
    if declaration.component.name != declaration.name:
        changed = "name"
    elif declaration.component.grid is not declaration.grid:
        changed = "grid"
    elif declaration.component.spec is not declaration.spec:
        changed = "spec"
    else:
        changed = None
    if changed is not None:
        raise ComponentError(
            f"Component '{declaration.name}' changed static {changed} during setup. "
            "Component name, grid, and spec must remain unchanged; return "
            "evolving state through SetupResult.payload."
        )
~~~

Call it immediately after the setup hook returns, before SetupResult validation.
